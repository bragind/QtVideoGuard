# Настройка детектора

## Базовый порядок

Настраивать параметры лучше на записи продолжительностью 10–30 минут, где есть
и полезный объект, и типичные помехи. Сначала включите бинарную маску, затем
меняйте по одному параметру.

| Проблема | Что изменить |
|---|---|
| Много отдельных белых точек | Увеличить «Удаление точек» с 3 до 5–7 px |
| Один объект разорван на части | Увеличить «Склейка объекта» с 9 до 13–21 px |
| Реакция на мелкие ветки/блики | Увеличить минимальную площадь, ширину и высоту |
| Ветка образует большую рыхлую рамку | Увеличить «Заполнение рамки» |
| Волны или трава проходят фильтр размера | Увеличить «Согласованность» |
| Короткие всплески дают тревогу | Увеличить число кадров подтверждения |
| Весь кадр срабатывает при тряске | Уменьшить порог «Глобальное движение» |
| Полезный медленный объект пропадает | Уменьшить минимальную скорость потока |
| Полезный объект не проходит при повороте | Уменьшить согласованность |
| Постоянно движется один участок | Добавить зону исключения |

## Параметры модели фона

### История

Количество кадров, используемых моделью. Большая история медленнее приспосабливается
к изменению сцены и дольше удерживает медленно движущийся объект. Для 25 кадров/с:

- `250–500` — быстрые изменения освещения и помещений;
- `500–1200` — улица, берег, территория;
- `1200+` — очень медленные объекты, стабильное освещение.

### Порог модели

Чем больше значение, тем сильнее пиксель должен отличаться от фона. Начните с
`24`. Для шумной камеры или воды попробуйте `30–50`. Слишком большой порог
разрушит маску объекта.

### Скорость обучения

`0.003` означает медленную адаптацию. Уменьшение до `0.001` дольше сохраняет
медленный или остановившийся объект, но хуже адаптируется к изменению света.
Увеличение до `0.01` быстрее успокаивает фон, но объект скорее исчезает.

## Геометрия

Минимальная площадь задаётся в процентах площади кадра, поэтому переносится
между разрешениями. При 1920×1080 значение `0.35%` соответствует примерно
7258 пикселям маски.

«Заполнение рамки» — отношение реальной площади контура к площади его
ограничивающего прямоугольника. У листвы и разреженной травы оно обычно меньше,
чем у плотного силуэта.

## Согласованность движения

Для каждого кандидата вычисляется оптический поток:

- значение около `1.0` означает, что видимые точки движутся преимущественно в
  одном направлении;
- значение около `0.0` соответствует взаимно компенсирующемуся хаотичному
  движению.

Типичный диапазон порога — `0.2–0.6`. На слабоконтрастном или медленном объекте
поток может быть ненадёжным; тогда уменьшите минимальную скорость либо временно
отключите эту проверку.

## Пример профиля для берега или акватории

```text
Модель:                    KNN
История:                   900 кадров
Порог модели:              32
Скорость обучения:         0.002
Минимальная площадь:       0.6 %
Минимальная ширина/высота: 70 / 50 px
Заполнение рамки:          25 %
Минимальная скорость:      0.8 px
Согласованность:           0.4
Подтверждение:             8 кадров
Глобальное движение:       35 %
```

Это только стартовая точка: размер объекта в пикселях зависит от фокусного
расстояния, разрешения и расстояния до зоны наблюдения.

## Как оценивать качество

Для каждой тестовой записи посчитайте:

- число истинных событий, которые детектор нашёл;
- число пропущенных событий;
- число ложных тревог в час;
- задержку от появления объекта до подтверждения;
- среднее время обработки кадра.

Настройку следует выбирать не по одному красивому фрагменту, а по нескольким
записям: штиль/ветер, день/сумерки, сухо/дождь. Для дальнейшего развития удобно
сохранять короткие клипы всех ложных тревог — они станут тестовым набором для
YOLO или другого классификатора.
